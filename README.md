# 📚 MongoDB CRUD API

A simple REST API built with Node.js, Express, and MongoDB for managing books.

## Features
- Add book
- Get books
- Update book
- Delete book

## Tech Stack
- Node.js
- Express.js
- MongoDB
- Mongoose

## API Endpoints
- GET /list
- POST /addBook
- PUT /updateBook/:book_id
- DELETE /deleteBook/:book_id

## Run Project
npm install
npm start
